### Photo Vault

`Django` `DRF` `MySQL` `Redis` `Cloudinary`

### Real-Time Chat API
A WebSocket-based group chat backend built with Django Channels. Supports named rooms, live messaging, reactions, join/leave notifications, and message history — all persisted in a database with Redis as the channel layer.

`Django Channels` `WebSockets` `Redis` `Django`
